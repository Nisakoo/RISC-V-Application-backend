# Диаграмма классов

[Редактируемая диаграмма draw.io](class-diagram.drawio).

Диаграмма свёрстана под лист A4 в книжной ориентации и построена вертикально, по образцу диаграммы классов бэкенда из примера РПЗ. Сверху в шахматном порядке расположены четыре страницы фронтенда с переносом длинных названий: «Страница ленты», «Страница плитки», «Страница черновика команды» и «Страница авторизации». Они подключаются к двум интерфейсам: API `riscv_commands` и API `users`. В каждый интерфейс входит одна связь от домена, а выходят связи ко всем использующим его страницам. Ниже находятся пакеты «Бэкенд» (домен команд RISC-V с семью методами и домен пользователей с тремя методами), «Модель» (три ORM-модели) и «База данных» (три таблицы с кратностями связей). Пунктирные стрелки показывают зависимости доменов от моделей и моделей от таблиц. Все связи проведены прямыми отрезками без изломов, пакеты не содержат пустых областей.
