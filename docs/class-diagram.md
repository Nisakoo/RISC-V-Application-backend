# Диаграмма классов

[Редактируемая диаграмма draw.io](class-diagram.drawio).

Диаграмма свёрстана под лист A4 в книжной ориентации, расположение повторяет принятый образец диаграммы классов. Сверху идут четыре пакета: «Фронтенд», «Бэкенд», «Модель» и «База данных»; названия расположены внутри пакетов. Во «Фронтенде» страницы стоят в две колонки: слева «Страница Ленты» и «Страница Добавления», справа «Страница Плитки» и «Страница Авторизации». Первые три подключаются к интерфейсу API `riscv_commands`, страница авторизации — к API `users`.

В «Бэкенде» находятся домен команд RISC-V с восемью методами (включая `feed/batch`) и домен пользователей с тремя методами. В «Модели» — три ORM-модели. Домен команд зависит от всех трёх: из `userRecord` читается логин создателя. В «Базе данных» три таблицы расположены в ряд, связь команд с пользователями проведена снизу; у связей указаны кратности.
