# Диаграмма последовательности

[Редактируемая диаграмма draw.io](sequence-diagram.drawio).

Диаграмма построена по образцу диаграммы последовательности из примера РПЗ курса и свёрстана под лист A4 в книжной ориентации. Она показывает весь набор HTTP-запросов бизнес-процесса создателя команды RISC-V без базы данных и нативного приложения: аутентификацию, получение списка команд с фильтром, создание черновика с изображением и видео, получение черновика, публикацию, получение ленты без идентификатора и по идентификатору с `next`, установку лайка.

Линии жизни — фронтенд создателя и экземпляры доменов из [диаграммы классов](class-diagram.md): «: Домен users» и «: Домен riscv_commands». Сообщения пронумерованы; сигнатура каждого запроса совпадает с методом домена на диаграмме классов, а в скобках указаны ключевые входные данные. Ответы показаны пунктиром с ключевыми выходными данными в скобках.
