# Диаграмма классов ЛР3

[Редактируемая диаграмма draw.io](lab3-class-diagram.drawio).

Диаграмма построена вертикально, по образцу диаграммы классов бэкенда из примера РПЗ. Сверху расположены четыре страницы фронтенда: «Лента», «Плитка», «Черновик команды» и «Авторизация». Они подключаются к двум интерфейсам: API `riscv_commands` и API `users`. В каждый интерфейс входит одна связь от домена, а выходят связи ко всем использующим его страницам. Ниже находятся пакеты «Бэкенд» (домен команд RISC-V с семью методами и домен пользователей с тремя методами), «Модель» (три ORM-модели) и «База данных» (три таблицы с кратностями связей). Пунктирные стрелки показывают зависимости доменов от моделей и моделей от таблиц.
