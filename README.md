# Backend

Серверная часть на Go для каталога команд RISC-V и программ, составленных из экземпляров команд.

## Лабораторная работа №1

В первой лабораторной используется серверная шаблонизация без JavaScript. Данные находятся в одной коллекции команд RISC-V в памяти. Реализованы три GET-контроллера:

- `/?id=4` — лента команд; без `id` открывается первая доступная команда, а кнопка «Следующий» содержит `id` следующей команды из коллекции;
- `/instruction/draft` — единственная команда в статусе черновика;
- `/instructions?min_operands=2&max_operands=3` — плитка команд с серверной фильтрацией по диапазону количества операндов.

Backend является самостоятельным проектом первой лабораторной. React-приложение из отдельного frontend-репозитория для запуска и защиты этой работы не требуется.

Перед первым запуском из каталога `backend` создайте локальный файл окружения:

```sh
cp docker/.env.example docker/.env
```

Укажите в нём собственные учётные данные MinIO, затем запустите приложение:

```sh
make run
```

Команда запускает MinIO, загружает медиафайлы и поднимает Go-бэкенд. Запуск только Go-сервера без управления инфраструктурой:

```sh
go run ./cmd/api
```

Сервер доступен по адресу `http://localhost:8080`: корневая страница сразу открывает ленту. Изображения и видео загружаются из публичного локального бакета MinIO `riscv-assets`.

## Структура

- `cmd/api` — точка входа приложения;
- `internal/domain` — предметные модели и DTO RISC-V;
- `internal/handler` — HTTP-обработчики;
- `internal/service` — сценарии получения ленты, черновика и фильтрации;
- `internal/repository` — коллекция команд и операции выборки;
- `internal/app` — сборка зависимостей и запуск сервера;
- `templates` — серверные HTML-шаблоны страниц и общая нижняя навигация;
- `resources/styles` — стили вертикального интерфейса без JavaScript;
- `assets` — изображения и видео инструкций для загрузки в MinIO;
- `docker` — конфигурация локальной инфраструктуры.

## Локальная инфраструктура

MinIO описан в [`docker/compose.yaml`](docker/compose.yaml). Для отдельного запуска инфраструктуры выполните:

```sh
make infra-up
```

Служебный контейнер создаёт публичный бакет `riscv-assets` и копирует в него изображения и видео из каталога [`assets`](assets) этого репозитория.

API MinIO: `http://localhost:9000`; панель управления: `http://localhost:9001`.

## Проверки

```sh
make test
```

Команда проверяет форматирование Go-кода, выполняет `go vet`, запускает Go-тесты и проверяет доступность и MIME-типы файлов в MinIO.
